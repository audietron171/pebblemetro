# pebblemetro

A simple Pebble watch app that shows upcoming departures for your favorite PTV stops.

Supports:

- Black-and-white Pebble's (Classic, Pebble 2/Duo)
- Square colour Pebble's (Time, Time 2)

No round Pebble support (Time Round or Time Round 2) sorry!
